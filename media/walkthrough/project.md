# Your first document

Choose New Project, select a folder and template, and name your document.
Inkwell verifies the workspace in the same setup flow and opens the new file.
If a tool needs repair or an existing file has a migration conflict, follow the
setup report before continuing. Edited project files are preserved.

Open Preview to write with a live document view. Compile PDF creates the PDF
beside your source document. If compilation fails, the last successful PDF stays
available while you resolve the error.

Draft and Print View work offline, including math and diagrams. The PDF viewer
remembers fit and zoom independently from the document's font settings. Use
Configure Document Style to change the document itself.

Run a code block to insert its result, or use Extract Code Block to Script to
keep the code in an editable project file. Rerunning unchanged code reuses its
verified result. Clear Code Block Cache preserves your scripts.
